# Changelog

## 0.3.0

- Added animated thinking and executing status indicators.
- Added live shell-command output with exit-code reporting.
- Added glob-based `find_files` tool.
- Added read-only `git_status` and `git_diff` tools.
- Added optional `delete_file` tool behind `--allow-delete`.
- Added colored deletion and update diffs.
- Added optional readline history through `GABCLI_HISTORY_FILE`.
- Added expanded tests and release documentation.

## 0.2.0

- Added colored unified previews for file writes.
- Added API-key prompt and GitHub packaging support.
